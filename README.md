# LogTime

> **Time is linear. Perception is not.**

LogTime 是一个以**非线性时间呈现**为核心的个人计时器。

它不改变真实时间的流逝速度，而是借助对数关系，让一段真实时间以另一种视觉节奏被看见。

[在线体验](https://yalways17.github.io/logtime/)

---

## 为什么是 LogTime？

真实时间始终匀速流逝，但人对时间的感受并不总是均匀。

心理物理学中的**韦伯–费希纳定律（Weber–Fechner law）**提出，感觉量与物理刺激之间可以呈现对数关系。LogTime 借鉴这一思想，将时间的视觉呈现设计为一种非线性的节奏。

其核心函数为：

$$
P(x)=\frac{\ln(1+a x)}{\ln(1+a)}
$$

其中：

* `x` 表示实际时间进度，范围为 `0 ~ 1`
* `P(x)` 表示视觉进度
* `a` 控制曲线的非线性程度

在 LogTime 中，**真实时间依然按照秒数正常流逝**，公式只作用于视觉呈现层。

> 时间没有改变，
> 只是换了一种方式被看见。

---

## 两种观看方式

### ◯ Ring

圆环将非线性进度转化为一个持续运动的时间轨迹。

灰色圆环代表尚未经过的部分，蓝色部分代表当前视觉进度。

百分比以较弱的方式显示在圆环边缘；中心的 `?` 提供关于时间感知与数学模型的简短解释。

### ▦ Grid

方格模式将时间离散成 **20 × 10，共 200 个格子**。

随着任务进行，格子逐渐被填充。

圆环与方格使用相同的数学进度，因此两种模式虽然视觉语言不同，但代表的是同一段时间。

## 功能

* 自定义任务名称
* 自定义任务时长
* 支持分钟、小时、天、周
* `Start Now` 立即开始
* 暂停 / 继续
* 显示或隐藏实际时间进度
* Ring / Grid 两种视觉模式
* 任务名称可直接编辑
* 任务完成时的 Emoji 庆祝效果
* 生成当前任务的 PNG 图片
* 自动保存当前状态
* 刷新页面后恢复任务状态
* 完成任务后保留 100% 状态
* 支持桌面与移动端响应式布局

任务状态与显示设置默认保存在浏览器的 `localStorage` 中，不需要注册账号，也不会上传到服务器。

## 一个任务是如何工作的？

创建任务时，可以输入任务名称，并设置持续时间与单位。当前版本支持：

```text
分钟
小时
天
周
```

点击 `Start Now` 后，程序将持续计算实际经过的时间，并将其转换为视觉进度。

实际进度：

```text
x = elapsed / totalDuration
```

视觉进度：

```text
P(x) = ln(1 + a·x) / ln(1 + a)
```

当前版本中：

```text
a = 2.0
```

数学模型被独立封装，因此视觉层只需要读取最终的进度值，而不需要分别处理圆环和方格的时间逻辑。

---

## 暂停与恢复

LogTime 不依赖单纯的 `setInterval` 累加时间。

程序通过时间戳计算实际经过的秒数，并将已经经过的时间与当前运行时间分开记录。

因此，即使页面更新频率发生变化，计时仍然以实际时间为依据。

暂停时，当前经过的时间会被保存；继续后，从新的时间戳继续计算。

---

## 完成

当任务达到 100% 时：

* 计时停止
* 进度停留在 100%
* 百分比移动至视觉中心
* `?` 淡出
* 页面触发一次 Emoji 庆祝动画
* 当前状态被保存

庆祝动画不会立即消失，而是保留在页面上，使完成后的画面可以被记录下来。

同时，用户可以通过菜单中的**生成图片**功能，将当前状态保存为 PNG。图片生成使用 `html2canvas`。

---

## 本地数据

LogTime 是一个纯前端项目。

任务名称、任务时长、当前进度、暂停状态、显示模式以及实际时间显示状态都会保存在浏览器本地。

```text
localStorage
└── time_app_state_v1
```

因此目前：

* 不需要后端
* 不需要数据库
* 不需要账号
* 不需要云端同步

数据只存在于当前浏览器环境中。

## 技术

LogTime 当前使用：

* **HTML**
* **CSS**
* **Vanilla JavaScript**
* **Canvas API**
* **localStorage**
* **html2canvas**

项目目前没有使用 React、Vue 或其他前端框架。

圆环由 Canvas 绘制，方格由 CSS Grid 构成。页面针对移动端进行了响应式适配，并根据屏幕尺寸调整圆环与 Grid 的尺寸。

## 项目结构

目前整个项目的核心逻辑集中在一个文件中：

```text
LogTime/
└── LogTime.html
```

主要代码结构：

```text
配置与常量
    ↓
状态管理
    ↓
数学模型
    ↓
Ring / Grid 渲染
    ↓
时间更新
    ↓
暂停 / 恢复
    ↓
任务管理
    ↓
完成庆祝
    ↓
图片生成
    ↓
localStorage
```

这种结构是刻意保持简单的：LogTime 首先是一个**独立的网页实验作品**，而不是一个需要复杂工程架构的生产型应用。

---

## 关于这个项目

LogTime 最初只是一个很简单的问题：

**如果真实时间始终匀速流逝，我们能不能换一种方式去看它？**

于是，一段普通的计时过程被拆成了三个层次：

**心理感知 → 数学关系 → 视觉呈现**

最终得到的不是一个试图改变时间的工具，而是一种观察时间的方式。
